# 03 - 类、对象与项目常见写法

> 本篇讲 `class`、对象、构造函数、服务注入。  
> 这些是看懂 `SpiritDeskService`、`Index.cshtml.cs`、实体类的关键。

---

## 1. 类是什么？

类是对象的模板。

```csharp
public class TaskItem
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
    public bool IsCompleted { get; set; }
}
```

可以理解为：

> `TaskItem` 规定了一条任务应该有哪些字段：编号、标题、是否完成。

---

## 2. 对象是什么？

对象是类创建出来的具体数据。

```csharp
var task = new TaskItem
{
    Title = "准备答辩展示",
    IsCompleted = false
};
```

| 类 | 对象 |
|----|------|
| `TaskItem` | 某一条具体任务 |
| `ChatMessage` | 某一条具体聊天消息 |
| `SpiritDefinition` | 某一个具体精灵 |

---

## 3. 属性初始化器

项目里经常这样创建对象：

```csharp
dbContext.ChatMessages.Add(new ChatMessage
{
    UserProfileId = profile.Id,
    Sender = "user",
    SpiritId = spirit.Id,
    Content = trimmed
});
```

这叫对象初始化器：创建对象时顺便给属性赋值。

相当于：

```csharp
var message = new ChatMessage();
message.UserProfileId = profile.Id;
message.Sender = "user";
message.SpiritId = spirit.Id;
message.Content = trimmed;
```

## 4. `public` 和 `private`

```csharp
public class SpiritDeskService
{
    public async Task SendMessageAsync(string message)
    {
        // 页面可以调用
    }

    private static string GetActionDisplayName(string actionType)
    {
        // 只有当前类内部能调用
    }
}
```

| 修饰符 | 含义 |
|--------|------|
| `public` | 公开，别的类能访问 |
| `private` | 私有，只能当前类内部用 |
| `static` | 属于类本身，不需要创建对象 |

答辩说法：

> 公开方法给页面调用，私有方法封装内部小逻辑，减少外部误用。

---

## 5. 构造函数与依赖注入

项目里有这种写法：

```csharp
public class IndexModel(SpiritDeskService spiritDeskService) : PageModel
{
    public SpiritDeskViewModel Desk { get; private set; } = default!;
}
```

这是 C# 的**主构造函数**写法。意思是：

> 创建 `IndexModel` 时，框架自动把 `SpiritDeskService` 传进来。

传统写法大概是：

```csharp
public class IndexModel : PageModel
{
    private readonly SpiritDeskService spiritDeskService;

    public IndexModel(SpiritDeskService spiritDeskService)
    {
        this.spiritDeskService = spiritDeskService;
    }
}
```

这就是依赖注入：

| 依赖 | 谁注入 | 用来做什么 |
|------|--------|------------|
| `SpiritDeskService` | ASP.NET Core | 调业务逻辑 |
| `SpiritDeskDbContext` | ASP.NET Core | 操作数据库 |
| `LlmReplyService` | ASP.NET Core | 调大模型回复 |

---

## 6. `readonly` 字段

```csharp
private readonly HttpClient _httpClient;
```

`readonly` 表示这个字段在构造后不能换成另一个对象。常用于依赖对象，防止中途被改掉。

字段名前面的 `_` 是命名习惯：

```csharp
private readonly ILogger<LlmReplyService> _logger;
```

表示它是类内部字段。

---

## 7. `required` 和 `init`

ViewModel 里常见：

```csharp
public required UserProfile Profile { get; init; }
```

| 写法 | 含义 |
|------|------|
| `required` | 创建对象时必须给这个属性赋值 |
| `init` | 初始化时能赋值，之后不建议再改 |
| `set` | 创建后也能修改 |

ViewModel 是“给页面展示的数据包”，通常创建好后给页面读，不希望到处乱改，所以会用 `init`。

---

## 8. 继承：`: PageModel`

```csharp
public class IndexModel : PageModel
{
}
```

冒号表示继承。

`IndexModel` 继承 `PageModel` 后，就拥有 Razor Pages 需要的能力，比如：

- `Page()`
- `RedirectToPage()`
- `TempData`
- `HttpContext`

答辩说法：

> PageModel 是 ASP.NET Core Razor Pages 提供的基类，我们自己的页面后台类继承它，才能处理页面请求和返回页面结果。

---

## 9. 最小答辩总结

> C# 用类描述对象模板，比如任务、聊天消息、用户档案。运行时会创建具体对象并给属性赋值。项目用依赖注入把数据库上下文、业务服务、大模型服务交给 PageModel 和 Service 使用，页面后台只调用服务，不直接堆复杂逻辑。
