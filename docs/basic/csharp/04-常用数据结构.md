# 04 - C# 常用数据结构

> 本篇讲项目里最常见的数据结构：数组、`List<T>`、`Dictionary<TKey,TValue>`、实体对象、可空值。  
> 重点是能看懂代码，不是背算法题。

---

## 1. 数据结构是什么？

数据结构就是“数据怎么装”。

| 数据结构 | 像什么 | 适合装什么 |
|----------|--------|------------|
| 数组 `T[]` | 固定格子的盒子 | 数量比较固定的数据 |
| `List<T>` | 可增减的列表 | 消息列表、任务列表、精灵列表 |
| `Dictionary<TKey,TValue>` | 查字典 | 根据 key 快速找到 value |
| 对象 | 一张表单 | 一条任务、一条消息、一个用户 |

---

## 2. 数组

数组长度固定：

```csharp
var choices = new[] { "rock", "paper", "scissors" };
```

访问数组：

```csharp
var first = choices[0]; // rock
```

注意：C# 下标从 `0` 开始。

| 下标 | 值 |
|------|----|
| `0` | `rock` |
| `1` | `paper` |
| `2` | `scissors` |

---

## 3. `List<T>`：最常用的列表

`List<T>` 表示一组同类型数据。

```csharp
List<ChatMessage> messages = await GetConversationMessagesAsync(profile, spirit.Id, 10);
```

读法：

> `List<ChatMessage>` = 很多条 `ChatMessage` 组成的列表。

常见操作：

```csharp
messages.Count          // 有多少条
messages.FirstOrDefault() // 第一条，没有则 null
messages.TakeLast(8)    // 取最后 8 条
messages.ToList()       // 转成 List
```

项目里的例子：

| 类型 | 含义 |
|------|------|
| `List<SpiritDefinition>` | 精灵列表 |
| `List<TaskItem>` | 任务列表 |
| `List<ChatMessage>` | 聊天消息列表 |

---

## 4. `Dictionary<TKey,TValue>`：键值对

字典通过 key 找 value。

```csharp
var limits = new Dictionary<string, int>
{
    ["checkin"] = 1,
    ["feed"] = 3,
    ["game"] = 5
};
```

| key | value |
|-----|-------|
| `checkin` | `1` |
| `feed` | `3` |
| `game` | `5` |

查询：

```csharp
if (limits.TryGetValue(actionType, out var limit))
{
    // 找到了对应上限
}
```

这句话意思是：

> 如果字典里有 `actionType` 这个 key，就把对应值放进 `limit`。

项目里的每日互动次数也用字典：

```csharp
Dictionary<string, int> DailyCounts
```

表示：

| 互动类型 | 今日次数 |
|----------|----------|
| `checkin` | 1 |
| `feed` | 2 |
| `game` | 0 |

## 5. 对象也是数据结构

实体类本身就是一种结构化数据。

```csharp
public class UserProfile
{
    public int Id { get; set; }
    public string Nickname { get; set; } = string.Empty;
    public int Mood { get; set; }
    public int Affinity { get; set; }
}
```

一条用户档案对象可以理解为：

| 字段 | 值 |
|------|----|
| `Id` | 1 |
| `Nickname` | zyx |
| `Mood` | 81 |
| `Affinity` | 34 |

## 6. `IReadOnlyList<T>` 是什么？

LLM 服务里有：

```csharp
IReadOnlyList<ChatMessage>? recentConversation
```

拆开看：

| 写法 | 含义 |
|------|------|
| `IReadOnlyList<ChatMessage>` | 只读消息列表 |
| `?` | 这个列表可以是 `null` |
| `recentConversation` | 最近对话上下文 |

为什么用只读？

> 这里服务只需要读取最近消息，不应该修改原列表，所以用只读接口更安全。

## 7. `DbSet<T>`：数据库里的表

`SpiritDeskDbContext` 里会看到：

```csharp
public DbSet<ChatMessage> ChatMessages => Set<ChatMessage>();
public DbSet<TaskItem> Tasks => Set<TaskItem>();
```

可以理解为：

| C# 写法 | 数据库含义 |
|---------|------------|
| `DbSet<ChatMessage>` | `ChatMessages` 表 |
| `DbSet<TaskItem>` | `Tasks` 表 |
| `DbSet<UserProfile>` | `UserProfiles` 表 |

`DbSet<T>` 不是普通列表，它代表数据库表，可以查询、添加、删除数据。

---

## 8. `Add`、`AddRange`、`RemoveRange`

```csharp
dbContext.ChatMessages.Add(new ChatMessage { Content = "hello" });
```

添加一条。

```csharp
dbContext.Tasks.AddRange(BuildDemoTasks(profile.Id));
```

添加多条。

```csharp
dbContext.ChatMessages.RemoveRange(messages);
```

删除多条。

最后通常要：

```csharp
await dbContext.SaveChangesAsync();
```

否则只是内存里标记了变化，还没真正写进数据库。

---

## 9. 最小答辩总结

> 项目里最常用的数据结构是 `List<T>` 和 `Dictionary<TKey,TValue>`。`List<T>` 用来保存多条同类型数据，例如任务列表、聊天记录；`Dictionary` 用来按 key 快速查值，例如每日互动次数。EF Core 里的 `DbSet<T>` 则代表数据库表，可以查询和保存实体对象。
