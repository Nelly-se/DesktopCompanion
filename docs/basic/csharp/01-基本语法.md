# 01 - C# 基本语法

> 本篇先讲最基础的写法：变量、类型、属性、字符串、注释。  
> 看完后，你能读懂实体类和 PageModel 里的大部分简单代码。

---

## 1. C# 文件长什么样？

一个 `.cs` 文件通常由这几部分组成：

```csharp
using SpiritDesk.Core.Entities;

namespace SpiritDesk.Web.Models;

public class ChatHistoryViewModel
{
    public required UserProfile Profile { get; init; }
    public required List<ChatMessage> Messages { get; init; }
}
```

| 部分 | 含义 |
|------|------|
| `using ...;` | 引入别的命名空间，类似“我要使用这个工具包” |
| `namespace ...;` | 当前文件属于哪个代码区域 |
| `public class ...` | 定义一个类 |
| `{ ... }` | 花括号包住类、方法、代码块 |
| `;` | 一句代码结束 |

## 2. 变量与类型

C# 是**强类型语言**：变量要知道自己是什么类型。

```csharp
string name = "卷卷晴";
int count = 3;
bool isCompleted = false;
DateTime now = DateTime.Now;
```

| 类型 | 含义 | 示例 |
|------|------|------|
| `string` | 字符串/文本 | `"hello"` |
| `int` | 整数 | `1`、`100` |
| `double` | 小数 | `3.14` |
| `bool` | 布尔值 | `true` / `false` |
| `DateTime` | 日期时间 | `DateTime.Now` |

也可以用 `var`：

```csharp
var name = "卷卷晴";
var count = 3;
```

`var` 不是没有类型，而是让编译器自动推断：

| 写法 | 实际类型 |
|------|----------|
| `var name = "卷卷晴";` | `string` |
| `var count = 3;` | `int` |

## 3. 字符串常见写法

### 3.1 普通字符串

```csharp
string message = "消息已发送。";
```

### 3.2 字符串插值

```csharp
var text = $"已切换为 {spirit.Name}。";
```

`$"..."` 里面可以用 `{变量}` 拼接内容。比 `+` 拼接更清楚。

### 3.3 判断空字符串

项目里经常看到：

```csharp
if (string.IsNullOrWhiteSpace(message))
{
    return;
}
```

意思是：如果 `message` 是 `null`、空字符串、或者全是空格，就直接返回。

## 4. 属性：类里面保存数据的字段

看 `ChatMessage` 这种实体类：

```csharp
public class ChatMessage
{
    public int Id { get; set; }
    public string Sender { get; set; } = string.Empty;
    public string? SpiritId { get; set; }
    public string Content { get; set; } = string.Empty;
    public DateTime CreatedAt { get; set; } = DateTime.Now;
}
```

| 写法 | 含义 |
|------|------|
| `public int Id { get; set; }` | 公开属性，能读取也能修改 |
| `= string.Empty` | 默认值是空字符串 |
| `string?` | 这个字符串允许为 `null` |
| `DateTime.Now` | 默认值是当前时间 |

答辩说法：

> 实体类里的属性会对应数据库表的字段，例如 `ChatMessage.Content` 对应聊天消息内容。

---

## 5. 可空类型：`?` 是什么意思？

```csharp
public string? SpiritId { get; set; }
public DateTime? DueAt { get; set; }
```

`?` 表示这个值可以没有。

| 写法 | 含义 |
|------|------|
| `string SpiritId` | 必须有字符串 |
| `string? SpiritId` | 可以是字符串，也可以是 `null` |
| `DateTime DueAt` | 必须有时间 |
| `DateTime? DueAt` | 截止时间可以不填 |

任务的截止时间就是典型例子：有些任务设置了时间，有些没有。

## 6. 注释

```csharp
// 单行注释：解释下一行代码

/*
  多行注释：
  可以写很多行
*/

/// <summary>
/// XML 文档注释，通常写在类或方法上。
/// </summary>
```

项目里的文件头注释主要是帮助答辩理解，不影响程序运行。

---

## 7. 最小答辩总结

如果老师问“C# 基本语法你怎么理解”，可以答：

> C# 是强类型语言，变量和属性都有明确类型。项目里用 `class` 定义实体、服务和页面模型，用属性保存数据，用 `string?`、`DateTime?` 表示可选字段，用 `public` 暴露页面或数据库需要访问的数据。
