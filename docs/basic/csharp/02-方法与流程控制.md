# 02 - 方法与流程控制

> 本篇讲代码怎么“动起来”：方法、参数、返回值、`if`、`switch`、循环。  
> PageModel 里的 `OnGetAsync`、`OnPostSendMessageAsync` 都属于方法。

---

## 1. 方法是什么？

方法就是一段可重复调用的逻辑。

```csharp
public async Task<IActionResult> OnGetAsync()
{
    Desk = await spiritDeskService.BuildViewModelAsync();
    return Page();
}
```

拆开看：

| 部分 | 含义 |
|------|------|
| `public` | 公开方法 |
| `async` | 这是异步方法，里面可以 `await` |
| `Task<IActionResult>` | 最终返回一个页面处理结果 |
| `OnGetAsync` | 方法名 |
| `()` | 参数列表，这里没有参数 |
| `{ ... }` | 方法体 |

---

## 2. 参数与返回值

```csharp
public async Task SendMessageAsync(string message, string? spiritId = null)
{
    if (string.IsNullOrWhiteSpace(message)) return;
    // 保存消息...
}
```

| 写法 | 含义 |
|------|------|
| `string message` | 必须传入一段消息 |
| `string? spiritId = null` | 可选参数，不传默认是 `null` |
| `Task` | 异步执行，但不返回具体数据 |

再看有返回值的方法：

```csharp
private static string SafeName(string nickname)
{
    return string.IsNullOrWhiteSpace(nickname) ? "你" : nickname.Trim();
}
```

`string` 表示这个方法会返回字符串。

---

## 3. `if` 判断

```csharp
if (string.IsNullOrWhiteSpace(message))
{
    return;
}
```

意思是：如果消息为空，就直接结束方法。

完整一点：

```csharp
if (task is null)
{
    return new OperationFeedback { Succeeded = false, Message = "未找到任务。" };
}
else
{
    task.IsCompleted = true;
}
```

项目里也常见更简洁的写法：

```csharp
if (spirit is null) return;
```

---

## 4. `switch` 分支

项目里根据互动类型发不同奖励：

```csharp
switch (actionType)
{
    case "checkin":
        profile.Mood += 5;
        break;
    case "feed":
        profile.Mood += 10;
        break;
}
```

也有表达式写法：

```csharp
private static string GetActionDisplayName(string actionType) => actionType switch
{
    "checkin" => "每日签到",
    "feed" => "投喂",
    _ => "互动操作"
};
```

| 写法 | 含义 |
|------|------|
| `"checkin" => "每日签到"` | 如果值是 `checkin`，返回“每日签到” |
| `_ => "互动操作"` | 其它情况的默认结果 |

## 5. 循环

### 5.1 `foreach`

遍历一组数据：

```csharp
foreach (var spirit in spirits)
{
    Console.WriteLine(spirit.Name);
}
```

在 Razor 页面里也常见：

```csharp
@foreach (var message in messages)
{
    <p>@message.Content</p>
}
```

意思是：每一条消息都渲染一个 `<p>`。

### 5.2 `for`

适合按数字循环：

```csharp
for (var i = 0; i < 3; i++)
{
    Console.WriteLine(i);
}
```

---

## 6. `return` 是什么？

`return` 有两个作用：

1. 返回结果
2. 结束当前方法

```csharp
if (string.IsNullOrWhiteSpace(title))
{
    return new OperationFeedback
    {
        Succeeded = false,
        Message = "请输入任务标题。"
    };
}
```

这里表示：标题为空时，直接返回失败结果，后面的创建任务逻辑不执行。

## 7. Razor Pages 里的方法命名

| 页面请求 | 后台方法 |
|----------|----------|
| 打开页面 `GET /Index` | `OnGetAsync()` |
| 表单 `asp-page-handler="SendMessage"` | `OnPostSendMessageAsync()` |
| 表单 `asp-page-handler="AddTask"` | `OnPostAddTaskAsync()` |

答辩说法：

> Razor Pages 通过方法名约定处理请求，`OnGet` 负责展示页面，`OnPostXxx` 负责处理页面上的表单提交。

---

## 8. 最小答辩总结

> C# 通过方法组织逻辑，方法可以接收参数并返回结果。页面打开走 `OnGetAsync`，按钮表单提交走 `OnPostXxxAsync`。业务中用 `if` 判断条件，用 `switch` 处理多种类型，用 `foreach` 遍历任务、消息、精灵列表。
