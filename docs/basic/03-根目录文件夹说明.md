# 03 - 根目录文件夹说明

打开仓库 `DesktopCompanion` 后，**先看这些文件夹**，别的可以暂时忽略。

## 必看

| 文件夹/文件 | 干什么 | 答辩要不要提 |
|-------------|--------|--------------|
| **`src/`** | 全部 C# 源代码（三个项目） | ✅ 必提 |
| **`SpiritDesk.sln`** | Visual Studio 解决方案，双击可打开整个项目 | ✅ 可说「用 sln 管理」 |
| **`README.md`** | 怎么运行、怎么配 API | 自己看，不必背 |
| **`需求文档.md`** | 功能列表、五精灵、演示流程 | ✅ 和需求对齐 |
| **`docs/`** | 文档（含本教程 `basic/`） | 可选 |
| **`deploy/`** | 服务器部署说明和脚本 | 若做了云端演示可提 |
| **`run-shell.ps1`** | 一键运行桌面版 | ✅ 演示用这条命令 |

## 运行后会生成（不用提交 Git）

| 文件夹 | 说明 |
|--------|------|
| **`artifacts/`** | 发布网站时生成的文件，用来上传服务器 |
| **`src/.../bin/`、`obj/`** | 编译产物与中间文件（**不提交 Git**）；专篇见 [12-csproj与obj文件夹详解.md](./12-csproj与obj文件夹详解.md) |

## 可以当不存在（答辩不用讲）

| 文件夹 | 说明 |
|--------|------|
| **`.cursor/`** | Cursor 编辑器配置，与项目功能无关 |
| **`temp/`** | 临时小工具，不是主程序 |
| **`_docs_backup/`** | 若存在，是文档备份，可删 |
| **`images/`** | 说明用图片，不是程序资源 |

## 配置文件（知道名字即可）

| 文件 | 作用 |
|------|------|
| **`.env.example`** | 大模型 API 配置示例；复制成 `.env` 填密钥 |
| **`.gitignore`** | Git 忽略 bin、.env 等 |
| **`NuGet.Config`** | 下载 C# 包用的源配置 |
| **`build.ps1`** | 编译整个解决方案 |

## 根目录关系图（背图）

```
DesktopCompanion/
├── src/              ← 写代码的地方（最重要）
├── deploy/           ← 上服务器
├── docs/             ← 文档
├── 需求文档.md        ← 做什么功能
├── README.md         ← 怎么跑
├── run-shell.ps1     ← 跑桌面版
└── SpiritDesk.sln    ← 打开整个工程
```
