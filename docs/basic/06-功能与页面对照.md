# 06 - 功能与页面对照

按**演示顺序**记：点哪里、对应哪个文件（实现细节可不说）。

## 演示流程表

| 步骤 | 你做什么 | 对应页面/路由 | 主要代码位置 |
|------|----------|---------------|--------------|
| 1 | 打开程序 | Shell 启动 → 自动打开 Web | `run-shell.ps1` → `MainWindow` |
| 2 | 登录（若开启） | `/Login` | `Pages/Login.*` |
| 3 | 注册新账号 | `/Register` | `Pages/Register.*` |
| 4 | 首次建档 / 选精灵 | `/Spirits/Select` | `Pages/Spirits/Select.*` |
| 5 | 首页看任务、日历 | `/` 或 `/Index` | `Pages/Index.*` |
| 6 | 和精灵聊天 | `/Chat` | `Pages/Chat.*` + `LlmReplyService` |
| 7 | 任务助手：签到投喂 | `/Assistant` | `Pages/Assistant.*` |
| 8 | 猜拳小游戏 | 首页内嵌 | `Index` + 前端 JS |
| 9 | 改设置、换精灵 | `/Settings` | `Pages/Settings.*` |
| 10 | 桌面浮球换精灵 | 右键菜单 | `CompanionBubbleWindow` + API |
| 11 | 关掉再开数据还在 | 重启 Shell/Web | SQLite + `SpiritDeskDbContext` |

## 五个精灵在代码里叫什么

逻辑里用 **英文 ID**（`SpiritIds.cs`），界面上显示中文名：

| 显示名 | 代码常量 / ID |
|--------|----------------|
| 卷卷晴 | `light` |
| 嘻嘻滴 | `water` |
| 贴贴朵 | `air` |
| 慢慢壤 | `soil` |
| 新新星 | `nutrition` |

**答辩说法**：Figma 出图 → 放到 `wwwroot/assets/images/` → 页面和浮球按 ID 加载对应 PNG。

## 网页里的精灵 vs 桌面浮球

| | 网页悬浮按钮 | 桌面浮球 |
|--|--------------|----------|
| 在哪 | 浏览器页面右下角 | Windows 桌面上，可拖 |

## 登录注册（你的模块）

| 功能 | 说明 |
|------|------|
| 注册 | 写入 `WebAccount` 表（SQLite） |
| 登录 | 校验账号密码，写 Cookie |
| Shell 本地自启 Web | **关闭**门禁，WebView2 直进主页 |
| Shell 连云端（`SPIRITDESK_REMOTE_BASEURL`） | **需要**在 WebView2 登录，浮球转发 Cookie |

**答辩专篇**：[15-登录注册功能详解.md](./15-登录注册功能详解.md)（流程、配置、演示脚本、老师问答）
| 云端 | 可开 `SpiritDesk:Auth`，用单演示账号保护 |

不必背 Cookie 实现，说清：**「演示用门禁，不是完整多用户系统」**（和需求文档一致）。

## 侧边栏导航（布局）

整体框架在 **`Pages/Shared/_Layout.cshtml`**：左侧菜单链到 Index、Chat、Assistant、Settings 等。

你改的薄荷色主要在 **`wwwroot/css/site.css`**，按钮类名如 `action-button mint`。
