# 02 - 整体结构一张图

## 核心：三个 C# 项目

解决方案文件：`SpiritDesk.sln`（在仓库最外层）

```
SpiritDesk.sln
    │
    ├── SpiritDesk.Core      ← 类库：放「数据长什么样」（实体类）
    │
    ├── SpiritDesk.Web       ← 网站：页面 + 业务 + 数据库（主力）
    │
    └── SpiritDesk.Shell     ← 桌面：窗口 + 浮球，里面打开 Web
```

## 谁引用谁

```
SpiritDesk.Core  （不引用别人，最底层）

SpiritDesk.Web   → 引用 Core

SpiritDesk.Shell → 引用 Core（浮球用 SpiritIds 常量）
                 → 引用 Web（保证编译最新 + 本地启动 Web.dll）
```

**记忆口诀**：Core 是字典，Web 是大脑，Shell 是 Windows 外壳。  
**详细版**（含 WPF/Razor/EF/API 解释、完整目录树）：见 [00-项目结构与排布.md](../00-项目结构与排布.md)。  
**EF 专讲**（零基础）：见 [13-EF是什么详解.md](./13-EF是什么详解.md)。

## 用户使用时数据怎么走

### 方式 A：只开网站

```
浏览器 → SpiritDesk.Web → SQLite 数据库文件
```

### 方式 B：开桌面版（答辩常用）

```
SpiritDesk.Shell
    ├── 主窗口（WebView2）里显示 SpiritDesk.Web 的页面
    ├── 自动在后台启动 SpiritDesk.Web（本机小端口）
    └── 桌面浮球（单独小窗口）通过接口问 Web「当前精灵是谁」
```

### 方式 C：桌面连云端

```
SpiritDesk.Shell → 浏览器/浮球访问 服务器上的 SpiritDesk.Web
（本机不启动 Web，只连 http://服务器IP）
```

## 和你工作相关的部分落在哪

| 你做的事 | 主要在 |
|----------|--------|
| 精灵形象、切图 | `SpiritDesk.Web/wwwroot/assets/images/` + Figma 源文件 |
| 登录、注册界面 | `SpiritDesk.Web/Pages/Login`、`Register` |
| 登录逻辑 | `Login.cshtml.cs`、`Register.cshtml.cs`、`Auth/` |
| 配色、布局 | `SpiritDesk.Web/wwwroot/css/site.css` |

部署相关在仓库 `deploy/` 文件夹（脚本和说明，不是 C# 业务代码）。
