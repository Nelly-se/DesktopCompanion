## 两个文件为什么成对出现？

Razor Pages 约定：

```
Login.cshtml      → 界面（像 HTML）
Login.cshtml.cs   → 后端（处理表单、跳转）
```

老师问「登录逻辑在哪」→ 指 **`Login.cshtml.cs`**，不是只指 `.cshtml`。  
完整讲解见 [15-登录注册功能详解.md](./15-登录注册功能详解.md)。
