## 一句话定位

SpiritDesk 使用 **ASP.NET Core Cookie 认证**：注册把账号写入 SQLite 的 `WebAccounts`，登录成功后浏览器带上 `SpiritDesk.Auth` Cookie；业务数据在 `UserProfiles` 里，通过 `AccountUsername` 和登录账号绑定。
