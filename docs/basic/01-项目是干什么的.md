# 01 - 项目是干什么的

## 一句话

**SpiritDesk = 桌面上的「小精灵伴侣」**：帮你记任务、聊聊天、签到投喂，选一个精灵陪着你；有 **网页版**，也有 **Windows 桌面版（带浮球）**。

## 不是啥

- 不是淘宝、不是后台管理系统  
- 不是完整微信那种「多用户社交平台」  
- 登录注册是**可选的演示门禁**，不是企业级账号中心  

## 技术栈（背这 5 个词就够）

| 词 | 干什么 |
|----|--------|
| **C# / .NET 9** | 整项目语言 |
| **ASP.NET Core** | 做网页和业务 |
| **WPF + WebView2** | Windows 桌面窗口 + 内嵌浏览器 |
| **SQLite** | 本地数据库，关机再开数据还在 |
| **Figma** | 画精灵、导出 PNG 切图 |

## 两个「端」别搞混

| 名称 | 是什么 | 谁用 |
|------|--------|------|
| **SpiritDesk.Web** | 网站（**Razor SSR** + `wwwroot` 静态资源） | 答辩演示、可部署到服务器 |
| **SpiritDesk.Shell** | 桌面程序（像桌宠） | 本机 Windows，里面有网页 + **桌面浮球** |

**老师常问**：浏览器里也能看到小精灵，和桌面浮球有啥区别？  
**答**：浏览器里的是**网页里的悬浮按钮**；真正贴在桌面上的浮球是 **Shell 程序** 做的，只有装了桌面版才有。

## 五个精灵（必背名字）

| 名字 | 一句话人设 |
|------|------------|
| 卷卷晴 | 催学习、搞效率 |
| 嘻嘻滴 | 逗你开心、补情绪 |
| 贴贴朵 | 关心人际、提醒联系 |
| 慢慢壤 | 劝休息、养身心 |
| 新新星 | 鼓励尝试新事物 |

用户第一次用要选其中一个，后面可在设置或浮球右键换。

## 答辩演示顺序（和需求文档一致）

1. 打开程序 → 建档 / 选精灵  
2. 首页：看任务、日历  
3. 聊天：和精灵说话  
4. 任务助手：签到、投喂  
5. 猜拳小游戏（在首页）  
6. 关掉再开：数据还在（说明 SQLite 有用）
