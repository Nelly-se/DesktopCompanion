# 09 - 构建、运行与部署

## 1. 环境要求

- **.NET 9 SDK**
- Windows 10/11（运行 Shell、WebView2 运行时）
- 可选：WebView2 Runtime、Python 3（仅 `upload-spiritdesk-web.py` 部署脚本）

## 2. 构建整个解决方案

```powershell
cd D:\Users\zyx\Desktop\DesktopCompanion
dotnet build SpiritDesk.sln -c Release
```

或使用根目录 `build.ps1`。

## 3. 运行 Web（仅浏览器）

```powershell
dotnet run --project .\src\SpiritDesk.Web\SpiritDesk.Web.csproj
```

- 默认 URL 见 `Properties/launchSettings.json`（如 `http://localhost:5160`）
- Development 下可参考 `appsettings.Development.json` 演示账号

### 大模型配置

1. 复制 `.env.example` 为 `.env`（仓库根或 `src/SpiritDesk.Web`）
2. 填写 `ARK_API_KEY` 等
3. 启动后 `DotEnvLoader` 自动加载

## 4. 运行 Shell（推荐答辩）

```powershell
.\run-shell.ps1
```

等价于：清除远程 URL 环境变量 → Release 构建 Shell → 启动 Shell → 自动起本地 Web。

手动方式：

```powershell
dotnet run --project .\src\SpiritDesk.Shell\SpiritDesk.Shell.csproj
```

### 连接云端 Web

```powershell
setx SPIRITDESK_REMOTE_BASEURL "http://你的服务器IP或域名"
```

新开终端运行 Shell；**不会**启动本地 Web 子进程。

## 5. 发布 Web 到服务器

```powershell
.\deploy\scripts\publish-web.ps1
```

输出目录：`artifacts\spiritdesk-web-publish`

上传与重启见 `deploy/aliyun/DEPLOYMENT.md`。宝塔常见路径：`/www/wwwroot/spiritdesk`，Nginx 反代到 Kestrel 端口（如 5000）。

环境变量示例：

```bash
SpiritDesk__Auth__Enabled=true
SpiritDesk__Auth__Username=演示用户名
SpiritDesk__Auth__Password=强密码
```

## 6. 仅部署 Web、不部署 Shell

云端职责：

- 提供浏览器访问与 API
- SQLite 或配置的数据目录落在服务器 `data/`

桌面浮球能力必须在学员本机运行 `SpiritDesk.Shell`，并指向云端 URL。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 编译 Shell 报 DLL 被锁定 | 关闭正在运行的 SpiritDesk.Shell |
| 浮球 API 401 | 云端开启认证，需浏览器先登录或配置 Cookie |
| 聊天无 AI 回复 | 检查 `.env` 中 `ARK_API_KEY`，无 Key 时走规则回复 |
| 数据库结构旧 | 删除 `data/spiritdesk.db` 或依赖 Bootstrapper/Ensure 逻辑 |
